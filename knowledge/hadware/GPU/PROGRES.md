# PROGRES Belajar GPU

Target: AI Inference Engineer yang paham GPU dari sisi hardware, memory, computation, architecture, dan performance optimization.

## Roadmap

| Tahap | Tema | Konsep |
|---|---|---|
| 1 | Fondasi | CPU vs GPU (latency vs throughput), Parallelism (data parallelism), Anatomi GPU secara garis besar |
| 2 | Execution Model | Thread, Warp, Thread Block, Grid, Streaming Multiprocessor (SM), Warp Scheduler, Warp Divergence |
| 3 | Processing Units | CUDA Core, Tensor Core, Presisi numerik (FP32/FP16/BF16/FP8/INT8), FLOPS |
| 4 | Memory Architecture | VRAM, Memory Hierarchy (register, shared memory, L1/L2, global), Memory Bandwidth, Coalescing |
| 5 | Performance & Bottleneck | Arithmetic Intensity, Roofline Model, Compute-bound vs Memory-bound, Occupancy, Profiling |
| 6 | GPU untuk AI Inference | Prefill vs Decode, KV Cache, Batching, Quantization, kebutuhan VRAM model |
| 7 | Optimization & Expert | Kernel optimization, Kernel fusion, Multi-GPU (NVLink, Tensor Parallelism), Serving engine |
