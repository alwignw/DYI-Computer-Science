Serverless adalah model eksekusi cloud computing di mana kamu cukup mengunggah kode aplikasi tanpa perlu mengurus, mengatur, atau merawat server secara manual. Server fisiknya tetap ada, tetapi seluruh pengelolaannya ditangani penuh oleh penyedia cloud (seperti AWS, Google Cloud, atau Vercel).

Analogi Sederhana :

Server Tradisional (Sewa Ruko): Kamu bayar sewa gedung penuh setiap bulan, tidak peduli toko lagi ramai atau sepi. Kamu juga wajib memperbaiki sendiri kalau ada kerusakan fasilitas.

Serverless (Taksi Online): Kamu hanya bayar sesuai jarak tempuh saat taksi dipakai. Kalau tidak ada perjalanan (tidak ada pengguna yang membuka aplikasimu), kamu tidak bayar sama sekali.
