**4. Cara Kerja**

* **Alur Langkah demi Langkah:**
1. **Entry Point Resolution:** Bundler menerima berkas utama (misal `src/index.js`) sebagai titik awal penelusuran.
2. **Parsing & AST Construction:** Bundler membaca isi berkas dan mengubah kode menjadi *Abstract Syntax Tree* (AST) untuk menganalisis sintaks secara terstruktur.
3. **Dependency Graph Building:** Bundler melacak seluruh klausa `import`/`require` secara rekursif. Setiap kali menemukan impor baru, berkas tersebut ditambahkan ke dalam grafik relasi.
4. **Transformation (Loaders):** Berkas yang ditemukan diproses sesuai pengaturannya. TypeScript diubah ke JavaScript, Sass diubah ke CSS, JSX diubah ke `React.createElement`.
5. **Bundling & Wrapping:** Semua modul yang sudah ditranspilasi dibungkus ke dalam fungsi terisolasi (*module closure*) untuk mencegah kebocoran variabel global, lalu digabungkan.
6. **Optimization & Output Generation:** Membuang kode tak terpakai (*tree shaking*), memadatkan nama variabel (*minification*), memecah berkas jika menggunakan *code splitting*, dan menuliskan berkas fisik ke folder `dist/`.



---

* **Contoh Sederhana:**
**Kode Sumber (`src/`):**
```javascript
// math.js
export const add = (a, b) => a + b;
export const multiply = (a, b) => a * b;

// index.js
import { add } from './math.js';
console.log(add(2, 3));

```


**Proses Bundler:**
* Melacak `index.js` → menemukan impor `add` dari `math.js`.
* *Tree Shaking*: Mendeteksi fungsi `multiply` tidak pernah dipanggil, lalu menghapusnya.
* *Output (`dist/bundle.js` ringkas):*
```javascript
// Bundler membungkus kode dalam IIFE (Immediately Invoked Function Expression)
(() => {
  const add = (a, b) => a + b;
  console.log(add(2, 3));
})();

```

* **Contoh Dunia Nyata (Aplikasi E-Commerce):**
1. **Input:** Ribuan berkas React (`.tsx`), modul CSS (`.module.scss`), gambar (`.png`), dan pustaka pihak ketiga (`node_modules/lodash`).
2. **Proses:**
* `ts-loader` mengubah `.tsx` menjadi JS standar.
* `sass-loader` & `mini-css-extract-plugin` menyatukan semua file SCSS menjadi satu berkas `main.css`.
* Dynamic import `import('./CheckoutPage')` secara otomatis memicu *Code Splitting*.


3. **Output (`dist/`):**
* `index.html` (ditulisi otomatis tag `<script>` oleh plugin).
* `main.a8b7c.js` (kode inti aplikasi & React).
* `checkout.f9e0d.js` (potongan kode halaman checkout, baru diunduh saat user mengklik "Checkout").
* `main.3d21a.css` (seluruh style aplikasi).
