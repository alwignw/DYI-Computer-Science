**8. Latihan**

Jawab 5 pertanyaan berikut untuk menguji pemahamanmu:

1. **Loader vs. Plugin:** Apa perbedaan mendasar antara tugas *Loader* dan *Plugin* dalam proses pengolahan berkas oleh bundler?
2. **Caching:** Mengapa penamaan berkas keluaran (*output*) disarankan menggunakan `[contenthash]` (contoh: `main.a8f9b2c3.js`) untuk rilis *production*?
3. **Tree Shaking:** Mengapa fitur *Tree Shaking* membutuhkan sintaks ES Modules (`import`/`export`) dan tidak dapat bekerja secara optimal jika menggunakan sintaks CommonJS (`require`/`module.exports`)?
4. **Performance:** Apa dampak negatif pada performa aplikasi jika seluruh kode aplikasi skala besar digabungkan menjadi satu berkas `bundle.js` raksasa tanpa menerapkan *Code Splitting*?
5. **Transpiler vs. Bundler:** Jika sebuah proyek sudah menggunakan Babel untuk mentranspilasi kode JavaScript modern menjadi ES5, apakah proyek tersebut masih membutuhkan Module Bundler? Jelaskan alasannya.
