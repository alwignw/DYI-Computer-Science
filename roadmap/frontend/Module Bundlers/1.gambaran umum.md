**1. Gambaran Besar**

* **Apa itu?**
Module Bundler adalah *build tool* di ekosistem JavaScript yang mengambil puluhan hingga ribuan berkas kode sumber terpisah (JS, CSS, HTML, gambar) beserta relasi dependensinya, lalu mengompilasi dan menggabungkannya (*bundle*) menjadi sejumlah kecil berkas statis teroptimasi yang siap dieksekusi oleh browser.
* **Mengapa Dibuat?**
Aplikasi web modern berkembang dari sekadar halaman statis menjadi aplikasi kompleks (*Single Page Applications*) dengan arsitektur modular. Browser secara *native* tidak dirancang untuk menangani ribuan *HTTP request* berkas terpisah secara efisien tanpa menurunkan performa jaringan dan mengacaukan ruang nama (*global namespace*).
* **Masalah yang Diselesaikan:**
* **Dependency Graph Resolution:** Melacak relasi `import`/`export` secara otomatis agar kode dieksekusi dalam urutan yang tepat tanpa kesalahan urutan pemuatan.
* **Namespace Isolation:** Membungkus kode dalam *scope* privat sehingga variabel antar-berkas tidak saling bentrok (*namespace pollution*).
* **Network Overhead:** Mengurangi ratusan *HTTP request* dengan memadatkan banyak berkas kecil menjadi beberapa aset utama (*bundle*).
* **Asset Transformation:** Mentranspilasi sintaks modern (TypeScript, JSX, ESNext) serta pra-pemroses CSS (Sass/Less) menjadi JS/CSS standar browser.
* **Production Optimization:** Mengurangi ukuran berkas melalui *Tree Shaking* (penghapusan *dead code*), *Minification* (pemadatan kode), dan *Code Splitting* (pemecahan berkas berdasarkan halaman/route).


* **Kapan Harus Digunakan?**
* Membangun aplikasi web modern skala menengah hingga besar dengan arsitektur berbasis modul (React, Vue, Svelte, atau Vanilla JS modular).
* Membutuhkan alur kerja pengembangan modern seperti TypeScript, transpilasi ES6+, pra-pemroses CSS, dan *Hot Module Replacement* (HMR).
* Membutuhkan optimasi performa rilis produksi (*code splitting*, *long-term caching*, pemadatan aset).


* **Kapan Jangan Digunakan?**
* **Situs Statis Sederhana:** Halaman *landing page* atau dokumen HTML/CSS/JS dasar yang cukup diimpor via tag `<script type="module">` native browser.
* **Node.js Backend Pure:** Aplikasi server-side Node.js modern yang sudah mendukung ES Modules secara native tanpa kebutuhan transpilasi TypeScript atau *distribution single file*.
* **Quick Prototyping:** Saat membuat demonstrasi cepat di mana konfigurasi *build tool* terlampau berlebihan (*over-engineering*).
