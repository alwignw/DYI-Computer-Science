**2. Fundamental**

* **Konsep Inti yang Wajib Dipahami:**
* **Entry Point:** Titik awal (*root*) di mana bundler mulai membaca aplikasi (biasanya `src/index.js` atau `src/main.tsx`). Dari titik ini, bundler menyisir semua pernyataan `import`/`require`.
* **Dependency Graph:** Peta pohon (*tree structure*) yang dibangun bundler secara otomatis untuk mencatat hubungan saling-ketergantungan antar-berkas berdasarkan `import`/`export`.
* **Loaders / Transformers:** Modul penerjemah. Secara bawaan, bundler hanya paham JavaScript/JSON. Loader bertugas mengubah berkas non-JS (TypeScript, JSX, CSS, SCSS, SVG, Gambar) menjadi modul JS yang valid agar bisa dimasukkan ke dalam grafik dependensi.
* **Plugins:** Ekstensi untuk manipulasi tingkat lanjut pada seluruh *build pipeline*. Berbeda dari loader yang bekerja *per berkas*, plugin bekerja pada level *bundle* (misal: memodifikasi HTML, menyuntikkan variabel lingkungan, menyunting berkas CSS akhir, mematikan log di produksi).
* **Output:** Konfigurasi hasil akhir. Menentukan direktori penampung (misal: `dist/`), nama berkas (*filename hashing*), serta target format (*ESM*, *CJS*, *UMD*).


* **Istilah-istilah Penting:**
* **Tree Shaking:** Proses penghapusan *dead code* (kode yang diekspor/diimpor tetapi tidak pernah dipanggil) melalui analisis statis sintaks ES Modules (`import`/`export`).
* **Code Splitting:** Teknik memecah *bundle* raksasa menjadi beberapa potongan berkas (*chunks*) kecil yang dimuat secara *on-demand* (lazy loading) atau paralel untuk mempercepat waktu muat awal halaman.
* **Chunk:** Potongan berkas JS/CSS terpisah hasil dari proses *code splitting*.
* **Source Map:** Berkas pemeta (berkstensi `.map`) yang menghubungkan kode terkompilasi/diminifikasi di produksi kembali ke baris kode sumber aslinya, sehingga mempermudah proses *debugging* di browser DevTools.
* **Hot Module Replacement (HMR):** Fitur saat *development* di mana bundler memperbarui modul di browser secara *real-time* ketika kode diubah, tanpa perlu melakukan pembaruan penuh halaman (*full page refresh*), menjaga *state* aplikasi tetap bertahan.


* **Hubungan Antar Konsep:**
> **Entry Point** → disisir membentuk **Dependency Graph** → setiap berkas non-JS diproses oleh **Loaders** → seluruh graf dioptimasi oleh **Plugins** (termasuk *Tree Shaking* & *Code Splitting*) → menghasilkan **Output** berupa *Bundle/Chunks* + **Source Maps**.
