## 7. Implementasi

Berikut adalah contoh konfigurasi dari tingkat dasar hingga standar industri (*production-grade*) menggunakan ekosistem JavaScript/TypeScript (ESLint & Prettier).

---

### A. Contoh Sederhana (*Basic Setup*)

Hanya butuh dua berkas konfigurasi di *root* proyek Anda:

#### 1. `.prettierrc` (Konfigurasi Formatter)

```json
{
  "semi": true,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "es5",
  "printWidth": 80
}

```

#### 2. `.eslintrc.json` (Konfigurasi Linter)

```json
{
  "env": {
    "browser": true,
    "es2021": true
  },
  "extends": [
    "eslint:recommended"
  ],
  "rules": {
    "no-unused-vars": "warn",
    "no-console": "off",
    "eqeqeq": "error"
  }
}

```

---

### B. Contoh Production-Grade

Dalam skala produksi, Linter & Formatter diintegrasikan agar tidak saling bentrok, mendukung TypeScript, dan berjalan otomatis saat `git commit`.

#### 1. `eslint.config.js` (ESLint Modern Flat Config + Prettier)

```javascript
import js from '@eslint/js';
import tseslint from 'typescript-eslint';
import eslintConfigPrettier from 'eslint-config-prettier';

export default [
  // 1. Target berkas yang di-lint
  { files: ['**/*.{js,mjs,cjs,ts}'] },
  
  // 2. Folder yang diabaikan (replacement .eslintignore)
  { ignores: ['dist/', 'node_modules/', 'coverage/'] },

  // 3. Preset Aturan Standar JS & TypeScript
  js.configs.recommended,
  ...tseslint.configs.recommended,

  // 4. Custom Rules Tim
  {
    rules: {
      'no-console': ['warn', { allow: ['warn', 'error'] }],
      'eqeqeq': ['error', 'always'],
      '@typescript-eslint/no-explicit-any': 'error',
    },
  },

  // 5. WAJIB DI AKHIR: Mematikan semua aturan ESLint yang berbenturan dengan Prettier
  eslintConfigPrettier,
];

```

#### 2. `.lintstagedrc.json` (Konfigurasi Git Pre-commit Hook)

```json
{
  "*.{js,ts}": [
    "prettier --write",
    "eslint --fix"
  ],
  "*.{json,md,yml}": [
    "prettier --write"
  ]
}

```

#### 3. `package.json` (Scripts Integration)

```json
{
  "scripts": {
    "lint": "eslint .",
    "lint:fix": "eslint . --fix",
    "format": "prettier --write .",
    "format:check": "prettier --check .",
    "prepare": "husky"
  }
}

```

---

### Penjelasan Setiap Bagian Utama

* **`eslintConfigPrettier` (di baris terakhir):** Paket `eslint-config-prettier` bertugas mematikan semua aturan ESLint yang berkaitan dengan tata letak visual (seperti spasi atau titik koma). Ini menjamin tidak ada "perang aturan" antara ESLint dan Prettier.
* **`@typescript-eslint/no-explicit-any: "error"`:** Menolak penggunaan tipe `any` pada TypeScript untuk menjaga keandalan *type checking*.
* **`.lintstagedrc.json`:** Mengatur agar saat developer mengetik `git commit`, Prettier dan ESLint **hanya mengeksekusi file yang sedang di-commit** (*staged files*), bukan seluruh repositori. Proses commit menjadi sangat cepat (hitungan milidetik).
* **`prettier --check .` (pada CI/CD):** Memeriksa apakah ada file yang belum diformat tanpa mengubah isinya. Sangat berguna di server CI untuk menolak PR yang kodenya belum di-format.
