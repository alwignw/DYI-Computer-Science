## What is Software Architecture?

**Software Architecture** adalah **struktur tingkat tinggi dari sebuah sistem perangkat lunak** — mendefinisikan bagaimana komponen-komponen sistem diorganisir, bagaimana mereka berinteraksi, dan prinsip-prinsip apa yang memandu desainnya.

### Definisi Singkat
> *"Architecture is about the important stuff. Whatever that is."*
> — Martin Fowler

Artinya: arsitektur adalah **keputusan-keputusan yang sulit diubah** di kemudian hari.

---

### 3 Elemen Utama Software Architecture

**1. Structure (Struktur)**
Bagaimana sistem dibagi menjadi komponen-komponen — misalnya service, module, layer.

**2. Interaction (Interaksi)**
Bagaimana komponen-komponen tersebut berkomunikasi satu sama lain — sync/async, API, event, dll.

**3. Principles & Constraints**
Aturan main yang disepakati tim — misalnya *"semua komunikasi antar service harus lewat API gateway"*.

---

### Mengapa Architecture Penting?

| Tanpa Architecture | Dengan Architecture |
|---|---|
| Sistem sulit di-scale | Mudah dikembangkan |
| Bug sulit dilacak | Komponen terisolasi |
| Onboarding lambat | Developer baru cepat paham |
| Perubahan = risiko besar | Perubahan terkontrol |

## Levels of Architecture

Ada **3 level** dalam software architecture:

### Level 1 — Application Architecture
- Scope: **satu aplikasi/service**
- Fokus: bagaimana kode diorganisir di dalam satu sistem
- Contoh: MVC, Clean Architecture, Layered Architecture
- Siapa yang pegang: Senior Dev / Tech Lead

### Level 2 — Solution Architecture
- Scope: **beberapa sistem yang bekerja bersama**
- Fokus: bagaimana aplikasi-aplikasi saling terintegrasi untuk menyelesaikan masalah bisnis tertentu
- Contoh: merancang sistem e-commerce yang melibatkan payment service, inventory, notification
- Siapa yang pegang: Solution Architect

### Level 3 — Enterprise Architecture
- Scope: **seluruh organisasi**
- Fokus: menyelaraskan teknologi dengan strategi bisnis perusahaan secara keseluruhan
- Contoh: roadmap teknologi 5 tahun, standarisasi platform di seluruh divisi
- Siapa yang pegang: Enterprise Architect / CTO

### Relevansi untuk Kamu

Sebagai seseorang yang sedang belajar jadi Software Architect, **fokus awal biasanya di Level 1 → Level 2**. Level 3 (Enterprise) lebih ke arah manajemen strategis dan biasanya datang setelah pengalaman bertahun-tahun.
