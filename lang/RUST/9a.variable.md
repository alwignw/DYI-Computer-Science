Di Rust, **variabel** bekerja dengan cara yang sedikit berbeda dibandingkan dengan bahasa pemrograman populer lainnya seperti Python, JavaScript, atau bahkan C++. Rust menerapkan aturan yang sangat ketat terkait variabel demi menjamin keamanan memori dan performa yang maksimal.

Mari kita bedah konsep variabel di Rust secara mendalam dan mendetail.

---

## 1. Immutability (Tidak Bisa Diubah secara Default)

Ini adalah karakteristik paling penting di Rust: **Secara default, semua variabel di Rust bersifat *immutable* (tidak dapat diubah nilainya setelah diinisialisasi).**

Jika Anda mencoba mengubah nilai variabel standar, Rust akan menolak untuk mengompilasi kode tersebut.

```rust
fn main() {
    let x = 5;
    println!("Nilai x adalah: {}", x);
    
    x = 6; // ❌ ERROR! Kompiler akan protes di sini.
    println!("Nilai x sekarang: {}", x);
}

```

### Kenapa harus *Immutable* secara default?

1. **Keamanan Konkurensi:** Jika banyak bagian kode (atau banyak *thread*) membaca variabel yang sama, dan dijamin tidak ada yang bisa mengubahnya, maka tidak akan pernah terjadi bentrokan data (*data race*).
2. **Optimasi Kompiler:** Kompiler Rust bisa melakukan optimasi kode yang lebih agresif karena tahu pasti bahwa nilai tersebut tidak akan pernah berubah sejak pertama kali dibuat.

---

## 2. Membuat Variabel Mutabel dengan `mut`

Jika Anda memang membutuhkan variabel yang nilainya bisa berubah-ubah (misalnya untuk perhitungan *counter* atau *looping*), Anda harus menyatakannya secara eksplisit menggunakan kata kunci **`mut`**.

```rust
fn main() {
    let mut x = 5; // Menggunakan 'mut'
    println!("Nilai x awal: {}", x);
    
    x = 6; // ✅ BERHASIL! Nilai x sekarang bisa diubah.
    println!("Nilai x baru: {}", x);
}

```

---

## 3. Perbedaan Variabel vs Konstanta (`const`)

Mungkin Anda berpikir: *"Kalau variabel di Rust tidak bisa diubah, apa bedanya dengan Konstanta?"*. Keduanya sangat berbeda di mata Rust.

Berikut adalah tabel perbedaannya:

| Fitur | Variabel `let` (Default) | Konstanta `const` |
| --- | --- | --- |
| **Kata Kunci** | `let x = 5;` | `const MAX_POIN: u32 = 100_000;` |
| **Pengubahan Nilai** | Bisa diubah jika ditambah `mut`. | **Sama sekali tidak bisa** diubah dengan cara apa pun. |
| **Tipe Data** | Bersifat *opsional* (bisa ditebak otomatis oleh Rust). | **Wajib ditulis** secara eksplisit (misal: `: u32`). |
| **Waktu Evaluasi** | Nilainya dihitung saat program berjalan (*runtime*). | Nilainya harus sudah pasti saat dikompilasi (*compile-time*). |
| **Skup Penulisan** | Hanya bisa di dalam fungsi. | Bisa ditulis di luar fungsi (skup global). |

*Catatan: Penulisan konstanta di Rust menggunakan konvensi huruf kapital semua dan garis bawah (`SCREAMING_SNAKE_CASE`).*

## 4. Konsep Variabel Shadowing (Pembayangan)

Rust memiliki fitur unik bernama **Shadowing**. Fitur ini memungkinkan Anda mendeklarasikan variabel baru dengan **nama yang sama persis** dengan variabel sebelumnya menggunakan kata kunci `let` lagi. Variabel kedua akan "membayangi" atau menyembunyikan variabel pertama.

Contoh penggunaan *Shadowing*:

```rust
fn main() {
    let x = 5;
    
    let x = x + 1; // x kedua (6) membayangi x pertama (5)
    
    {
        let x = x * 2; // x ketiga (12) membayangi x kedua di dalam ruang lingkup ini
        println!("Nilai x di dalam inner scope: {}", x); // Output: 12
    }
    
    println!("Nilai x di outer scope: {}", x); // Output: 6
}

```

### Apa bedanya Shadowing dengan `mut`?

1. **Mengubah Tipe Data:** Dengan *shadowing*, kita bisa mengubah tipe data dari variabel tersebut tanpa harus membuat nama variabel baru. Jika menggunakan `mut`, tipe datanya harus tetap sama.
```rust
// ✅ BERHASIL dengan Shadowing
let ruang_teks = "   "; // Tipe data: &str (teks)
let ruang_teks = ruang_teks.len(); // Tipe data berubah jadi usize (angka panjang teks)

// ❌ ERROR dengan mut
let mut ruang_teks = "   ";
ruang_teks = ruang_teks.len(); // Kompiler akan protes karena tipe data berubah

```


2. **Kembali ke Immutability:** Setelah proses *shadowing* selesai, variabel tersebut tetap bersifat *immutable* (tidak bisa diubah secara tidak sengaja tanpa `let`).

---

## 5. Alokasi Memori Variabel di Rust

Bagaimana variabel disimpan di memori komputer ditentukan oleh tipe datanya, dan Rust sangat efisien dalam hal ini:

* **Tipe Data Primitif (Statis):** Variabel dengan ukuran pasti seperti integer (`i32`), boolean (`bool`), atau karakter (`char`) akan langsung disimpan di **Stack Memori**. Proses alokasi dan penghapusannya instan.
* **Tipe Data Dinamis:** Variabel yang ukurannya bisa membesar/mengecil saat program berjalan, seperti `String` atau `Vec` (Vector), datanya akan disimpan di **Heap Memori**, sedangkan alamat penunjuknya (*pointer*) disimpan di **Stack**.

Karena adanya konsep **Ownership**, memori tempat variabel ini disimpan akan otomatis dibersihkan oleh Rust tepat pada saat variabel tersebut keluar dari ruang lingkupnya (*out of scope* / tanda kurung kurawal tutup `}`).
