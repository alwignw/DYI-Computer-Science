Rust adalah bahasa pemrograman yang **statically typed** (bertipe statis). Artinya, Rust harus mengetahui tipe data dari semua variabel pada saat *compile time* (waktu kompilasi). 

Meskipun demikian, Rust memiliki fitur **type inference** (inferensi tipe), di mana compiler sering kali bisa menebak tipe data secara otomatis berdasarkan nilai yang diberikan. Namun, pada kasus tertentu (seperti saat memanggil fungsi yang memiliki banyak kemungkinan tipe *return*), kita wajib menuliskan anotasi tipe secara eksplisit.

Secara garis besar, tipe data bawaan (primitive) di Rust dibagi menjadi dua kategori utama: **Scalar** (Skalar) dan **Compound** (Majemuk). Selain itu, Rust memiliki penanganan **String** yang sangat unik dan penting untuk dipahami.

Berikut adalah penjelasan detailnya:

---

### 1. Tipe Data Skalar (Scalar Types)
Tipe skalar merepresentasikan satu nilai tunggal. Rust memiliki 4 tipe skalar utama:

#### A. Integer (Bilangan Bulat)
Integer adalah angka tanpa pecahan. Rust membagi integer menjadi dua kategori: **Signed** (bertanda, bisa bernilai negatif dan positif) dan **Unsigned** (tanpa tanda, hanya nilai positif dan nol).

| Ukuran (Size) | Signed (Bertanda) | Unsigned (Tanpa Tanda) |
| :--- | :--- | :--- |
| 8-bit | `i8` | `u8` |
| 16-bit | `i16` | `u16` |
| 32-bit | `i32` | `u32` |
| 64-bit | `i64` | `u64` |
| 128-bit | `i128` | `u128` |
| Arsitektur | `isize` | `usize` |

*   **Default:** Jika Anda menulis `let x = 42;`, Rust akan menganggapnya sebagai **`i32`** karena secara umum ini adalah tipe yang paling optimal dan cepat di arsitektur modern.
*   **`isize` dan `usize`:** Ukurannya bergantung pada arsitektur komputer (64-bit atau 32-bit). Tipe ini biasanya digunakan untuk *indexing* array atau operasi memori.
*   **Overflow:** Pada mode *Debug*, Rust akan melakukan *panic* (crash) jika terjadi integer overflow. Pada mode *Release*, Rust akan melakukan *two's complement wrapping* (misal `u8` dari 255 akan kembali ke 0).

#### B. Floating-Point (Bilangan Pecahan)
Digunakan untuk angka dengan koma/desimal. Rust hanya memiliki dua tipe floating-point:
*   **`f32`** (single precision, 32-bit)
*   **`f64`** (double precision, 64-bit)

```rust
let x = 2.0;      // Default adalah f64
let y: f32 = 3.0; // f32
```
*   **Default:** Rust menggunakan **`f64`** sebagai default karena pada CPU modern, `f64` memiliki presisi yang lebih tinggi dengan kecepatan komputasi yang hampir sama dengan `f32`.

#### C. Boolean (Logika)
Tipe boolean di Rust hanya memiliki dua nilai: `true` dan `false`.
*   **Ukuran:** 1 byte.
*   **Anotasi:** `bool`.

```rust
let t: bool = true;
let f = false; // Type inference: bool
```

#### D. Character (Karakter)
Tipe `char` di Rust merepresentasikan **Unicode Scalar Value**. Ini jauh lebih *powerful* dibandingkan `char` di bahasa C/C++ atau Java.
*   **Ukuran:** 4 bytes (32-bit).
*   **Notasi:** Menggunakan petik tunggal (`' '`).
*   **Kelebihan:** Bisa menampung huruf alfabet, huruf Kanji/Jepang, emoji, dan karakter khusus lainnya.

```rust
let c = 'z';
let z = 'ℤ';
let heart_eyed_cat = '😻'; // Valid di Rust!
```

### 2. Tipe Data Majemuk (Compound Types)
Tipe majemuk mengelompokkan beberapa nilai menjadi satu tipe. Rust memiliki dua tipe majemuk primitif:

#### A. Tuple
Tuple mengelompokkan beberapa nilai dengan **tipe data yang berbeda-beda** ke dalam satu variabel. Ukuran tuple bersifat *fixed* (tetap) dan tidak bisa bertambah setelah dideklarasikan.

```rust
let tup: (i32, f64, u8) = (500, 6.4, 1);
```
**Cara mengakses nilai Tuple:**
1.  **Destructuring** (Membongkar):
    ```rust
    let (x, y, z) = tup;
    println!("Nilai y adalah: {}", y);
    ```
2.  **Notasi Titik** (Indexing):
    ```rust
    let first = tup.0;
    let second = tup.1;
    ```
*   **Unit Type `()`**: Tuple tanpa nilai apa pun ditulis sebagai `()`. Ini disebut *unit type* dan merepresentasikan "nilai kosong" (mirip dengan `void` di bahasa lain atau `None`/`null` dalam konteks *return type*).

#### B. Array
Berbeda dengan tuple, semua elemen di dalam array **harus memiliki tipe data yang sama**. Sama seperti tuple, ukuran array di Rust bersifat *fixed* (tetap) dan dialokasikan di *Stack*.

```rust
let a: [i32; 5] = [1, 2, 3, 4, 5]; // Array i32 dengan panjang 5

// Cara cepat membuat array dengan nilai yang sama
let b = [3; 5]; // Sama dengan [3, 3, 3, 3, 3]
```
**Akses dan Keamanan (Bounds Checking):**
```rust
let first = a[0];
let second = a[1];
// let crash = a[10]; // ERROR! Compiler/Runtime akan PANIC karena index out of bounds.
```
*Catatan:* Jika Anda butuh kumpulan data yang ukurannya bisa berubah (dinamis), Rust menyediakan **`Vec<T>`** (Vector) yang dialokasikan di *Heap*, bukan menggunakan array primitif.

### 3. Tipe Data String (Sangat Penting!)
Pemula di Rust sering bingung dengan String karena Rust memiliki dua cara utama untuk merepresentasikan teks:

#### A. `&str` (String Slice)
*   Ini adalah referensi ke deretan karakter UTF-8 yang dialokasikan di suatu tempat (biasanya di dalam *binary executable* program / *hardcoded*).
*   Bersifat **Immutable** (tidak bisa diubah).
*   Sering disebut sebagai *string literal*.

```rust
let s: &str = "Halo, Rust!";
```

#### B. `String` (String Type)
*   Ini adalah tipe string yang dialokasikan di **Heap**.
*   Bersifat **Mutable** (bisa diubah, ditambah, atau dikurangi) dan ukurannya dinamis.
*   Dibuat menggunakan `String::from()` atau `.to_string()`.

```rust
let mut s = String::from("Halo");
s.push_str(", Dunia!"); // Valid karena s adalah String (Heap-allocated)
```

### 4. Konversi Tipe (Type Casting)
Rust **tidak melakukan konversi tipe secara implisit** (otomatis). Ini adalah desain keamanan untuk mencegah bug yang sering terjadi di bahasa C/C++ (seperti *data loss* saat mengubah `f64` ke `i32` tanpa sadar).

Anda harus menggunakan kata kunci **`as`** untuk melakukan konversi eksplisit:

```rust
let x: i32 = 10;
let y: f64 = x as f64; // Konversi eksplisit dari i32 ke f64

let z: u8 = 256; // ERROR! Compile-time error karena 256 di luar batas u8 (max 255)
let z: u8 = (256 % 256) as u8; // Valid
```

### 5. Tipe Data Lanjutan (Custom & Advanced Types)
Meskipun bukan tipe primitif, Rust sangat bergantung pada tipe data kustom berikut untuk pemrograman sehari-hari:

1.  **Struct:** Digunakan untuk membuat objek data kustom (mirip *class* tanpa *method* atau *record* di bahasa lain).
2.  **Enum (Enumerations):** Sangat *powerful* di Rust. Enum bisa menyimpan data di setiap variannya. Ini adalah dasar dari penanganan *error* dan *null safety* di Rust.
    *   `Option<T>`: Menggantikan `null` (Bisa `Some(value)` atau `None`).
    *   `Result<T, E>`: Untuk penanganan *error* (Bisa `Ok(value)` atau `Err(error)`).
3.  **Slice (`&[T]`):** Referensi ke bagian berurutan dari sebuah koleksi (seperti array atau vector) tanpa mengambil kepemilikannya (*ownership*).
4.  **References (`&T` dan `&mut T`):** Pointer aman (*safe pointers*) yang merujuk pada nilai di memori tanpa memindahkan *ownership*.

---

### Kesimpulan Filosofi Tipe Data Rust
Sistem tipe data di Rust dirancang dengan prinsip **"Fearless Concurrency"** dan **Memory Safety**:
1.  **Tidak ada `null` pada tipe primitif:** Mencegah *NullPointerException*.
2.  **Batas ukuran yang ketat:** Mencegah *buffer overflow* pada Array.
3.  **Tidak ada *implicit casting*:** Mencegah hilangnya presisi data secara diam-diam.
4.  **UTF-8 Native:** Karakter dan String dirancang untuk standar Unicode global sejak hari pertama.
