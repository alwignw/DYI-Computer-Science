## Ide dasarnya

Unicode memberi **nomor** ke setiap karakter di dunia. Nomor ini ditulis dalam heksadesimal dengan awalan `U+`.

```
'A'  → U+0041  (desimal 65)
'日' → U+65E5
'😀' → U+1F600
```

`char` di Rust pada dasarnya adalah **nomor itu**, disimpan dalam 32 bit.

## Apa arti "rentang"?

Nomor Unicode berjalan dari `U+0000` sampai `U+10FFFF`. Bayangkan sebagai deretan nomor rumah di satu jalan panjang:

```
U+0000 ............ U+D7FF  |  U+D800 ... U+DFFF  |  U+E000 ............ U+10FFFF
   ✅ boleh jadi char       |   ❌ terlarang       |     ✅ boleh jadi char
```

Jadi `char` boleh bernilai apa saja di jalan itu, **kecuali blok tengah** `U+D800` sampai `U+DFFF`.

## Kenapa blok tengah dilarang?

Blok itu disebut **surrogate**. Ia tidak dipakai untuk karakter apa pun. Fungsinya khusus: format **UTF-16** memakainya sebagai "kode bantu" untuk menulis karakter besar (seperti emoji) dengan memakai dua potong 16-bit.

Karena itu, nomor-nomor di blok ini **bukan karakter sungguhan**. Unicode menyebut nomor yang valid sebagai *scalar value*, yaitu semua nomor **kecuali** surrogate. Rust hanya mengizinkan scalar value menjadi `char`.

## Buktinya di kode

```rust
fn main() {
    // 0x41 = U+0041 -> valid
    println!("{:?}", char::from_u32(0x41));     // Some('A')

    // 0xD800 = awal blok surrogate -> tidak valid
    println!("{:?}", char::from_u32(0xD800));   // None

    // 0xE000 = tepat setelah blok surrogate -> valid lagi
    println!("{:?}", char::from_u32(0xE000));   // Some('\u{e000}')

    // melewati batas atas -> tidak valid
    println!("{:?}", char::from_u32(0x110000)); // None
}
```

`char::from_u32` mengembalikan `None` kalau nomornya tidak valid. Itulah sebabnya hasilnya berupa `Option`.

## Intinya

Kamu tidak perlu menghafal angka-angkanya. Yang perlu diingat: **tidak semua angka `u32` adalah `char` yang valid**. Rust menjamin bahwa setiap `char` pasti valid, jadi konversi dari `u32` harus lewat `char::from_u32()` yang memeriksa dulu.

Apakah sudah lebih jelas? Kalau masih ada yang membingungkan, tanyakan saja bagian mana, misalnya soal heksadesimal (`0x...`) atau perbedaan UTF-8 dan UTF-16.
