# Tuple di Rust

## Apa itu tuple?

**Tuple** adalah cara mengelompokkan beberapa nilai dengan **tipe yang boleh berbeda-beda** ke dalam satu tipe gabungan. Dua sifat utamanya:

- **Ukuran tetap**: setelah dibuat, jumlah elemennya tidak bisa bertambah atau berkurang.
- **Tipe tiap elemen bisa berbeda**: berbeda dengan array yang semua elemennya harus bertipe sama.

## Membuat tuple

```rust
fn main() {
    let data: (i32, f64, &str) = (500, 6.4, "halo");
    println!("{:?}", data); // (500, 6.4, "halo")
}
```

Tipenya ditulis dalam tanda kurung: `(i32, f64, &str)`. Biasanya anotasi tipe boleh dihilangkan karena Rust bisa menebaknya:

```rust
let data = (500, 6.4, "halo");
```

## Mengakses elemen

Ada dua cara.

**1. Destructuring** (memecah tuple menjadi variabel terpisah):

```rust
let data = (500, 6.4, "halo");
let (x, y, z) = data;

println!("x = {x}, y = {y}, z = {z}");
```

**2. Notasi titik dengan indeks** (dimulai dari 0):

```rust
let data = (500, 6.4, "halo");

println!("{}", data.0); // 500
println!("{}", data.1); // 6.4
println!("{}", data.2); // halo
```

Perhatikan: pakai `data.0`, **bukan** `data[0]`. Kurung siku hanya untuk array dan vector.

## Tuple yang bisa diubah (mutable)

```rust
let mut posisi = (10, 20);
posisi.0 = 15;
println!("{:?}", posisi); // (15, 20)
```

Nilai elemen bisa diubah, tetapi **tipenya harus tetap sama** dan jumlah elemennya tidak bisa diubah.

## Kegunaan paling umum: mengembalikan banyak nilai dari fungsi

Rust tidak punya sintaks khusus untuk return banyak nilai, jadi tuple dipakai untuk itu:

```rust
fn hitung(a: i32, b: i32) -> (i32, i32) {
    (a + b, a * b)
}

fn main() {
    let (jumlah, kali) = hitung(3, 4);
    println!("jumlah = {jumlah}, kali = {kali}"); // 7 dan 12
}
```

## Unit type: tuple kosong `()`

Tuple tanpa elemen disebut **unit** dan ditulis `()`. Ini adalah nilai yang dikembalikan secara implisit oleh fungsi yang tidak mengembalikan apa-apa:

```rust
fn sapa() {          // sama dengan: fn sapa() -> ()
    println!("Halo!");
}
```

## Tuple vs Array

| | Tuple | Array |
|---|---|---|
| Tipe elemen | Boleh berbeda | Harus sama |
| Ukuran | Tetap | Tetap |
| Akses | `t.0`, `t.1` | `a[0]`, `a[1]` |
| Bisa di-loop | Tidak | Ya |

## Hal yang perlu diingat

- Tuple dengan satu elemen harus memakai koma di akhir: `(5,)`. Tanpa koma, `(5)` hanya angka 5 dalam kurung.
- Untuk mencetak tuple, gunakan `{:?}` (Debug), bukan `{}`.
- Kalau datanya mulai banyak atau butuh nama yang jelas, pertimbangkan `struct`. `data.0` kurang informatif dibanding `orang.nama`.
