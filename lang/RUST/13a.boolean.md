# Tipe Data Boolean di Rust

## Dasar

Tipe `bool` hanya punya dua nilai: `true` dan `false`. Ukurannya **1 byte** di memori.

```rust
fn main() {
    let sudah_login = true;
    let punya_akses: bool = false; // anotasi tipe eksplisit (opsional)

    println!("{} {}", sudah_login, punya_akses);
}
```

## Operator yang Menghasilkan Boolean

**Perbandingan** (hasilnya `bool`):

```rust
let a = 10;
let b = 20;

println!("{}", a == b); // false
println!("{}", a != b); // true
println!("{}", a < b);  // true
println!("{}", a >= b); // false
```

**Operator logika:**

```rust
let x = true;
let y = false;

println!("{}", x && y); // AND  -> false
println!("{}", x || y); // OR   -> true
println!("{}", !x);     // NOT  -> false
```

`&&` dan `||` bersifat **short-circuit**: sisi kanan tidak dievaluasi jika hasilnya sudah pasti dari sisi kiri.

```rust
let hasil = false && fungsi_mahal(); // fungsi_mahal() tidak pernah dipanggil
```

## Boolean dalam Percabangan

Di Rust, kondisi `if` **harus bertipe `bool`**. Tidak ada konversi implisit seperti di C atau JavaScript.

```rust
let umur = 20;

if umur >= 17 {
    println!("Boleh punya KTP");
} else {
    println!("Belum boleh");
}

// if adalah ekspresi, jadi bisa dipakai untuk memberi nilai
let status = if umur >= 17 { "dewasa" } else { "anak" };
```

Ini tidak akan compile:

```rust
let n = 1;
if n { // ERROR: expected `bool`, found integer
    println!("benar");
}
```

Kamu harus menulis `if n != 0` atau `if n == 1`. Aturan ini mencegah bug yang umum terjadi di bahasa lain.

## Hal Penting Lainnya

**1. Konversi bool ke integer perlu eksplisit:**

```rust
let b = true;
let angka = b as i32;  // 1
let nol = false as u8; // 0
```

Sebaliknya (integer ke bool) **tidak bisa** dengan `as`. Gunakan perbandingan: `angka != 0`.

**2. Nilai default:**

```rust
let d: bool = Default::default(); // false
```

**3. Method berguna pada `bool`:**

```rust
let aktif = true;

// then: menghasilkan Option, Some(...) jika true
let hasil = aktif.then(|| "nilai");   // Some("nilai")
let kosong = false.then(|| "nilai");  // None

// then_some: versi yang nilainya langsung diberikan
let hasil2 = aktif.then_some(42);     // Some(42)
```

**4. Boolean bisa dibandingkan dan diurutkan**, dengan `false < true`:

```rust
println!("{}", false < true); // true
```

**5. Operator bitwise juga berlaku:**

```rust
let a = true;
let b = false;
println!("{}", a & b);  // false (tanpa short-circuit)
println!("{}", a | b);  // true
println!("{}", a ^ b);  // true (XOR)
```

Bedanya dengan `&&` dan `||`: `&` dan `|` selalu mengevaluasi kedua sisi.

## Contoh Gabungan

```rust
fn is_valid_password(pw: &str) -> bool {
    let panjang_ok = pw.len() >= 8;
    let ada_angka = pw.chars().any(|c| c.is_ascii_digit());

    panjang_ok && ada_angka
}

fn main() {
    println!("{}", is_valid_password("abc123"));      // false
    println!("{}", is_valid_password("rahasia2024")); // true
}
```
