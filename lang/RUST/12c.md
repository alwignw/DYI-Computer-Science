Pertanyaan bagus, karena `isize` dan `usize` berbeda dari tipe lain yang ukurannya sudah tetap.

## Intinya

Tipe seperti `i32` atau `u64` punya ukuran **tetap**: `i32` selalu 32 bit, di komputer mana pun. Sedangkan `isize` dan `usize` ukurannya **mengikuti arsitektur komputer** tempat program dijalankan:

| Arsitektur | Ukuran `usize` / `isize` | Setara dengan |
|---|---|---|
| 32-bit | 32 bit | `u32` / `i32` |
| 64-bit | 64 bit | `u64` / `i64` |

Hampir semua komputer dan laptop modern memakai 64-bit, jadi biasanya `usize` = 64 bit.

Kamu bisa cek sendiri:

```rust
fn main() {
    println!("{}", std::mem::size_of::<usize>()); // 8 (artinya 8 byte = 64 bit)
    println!("{}", usize::MAX); // 18446744073709551615 di komputer 64-bit
}
```

## Arti Huruf-hurufnya

- `usize` = **u**nsigned + **size** → angka tak bertanda (≥ 0), ukuran mengikuti arsitektur
- `isize` = **i**nteger (signed) + **size** → angka bertanda (bisa negatif), ukuran mengikuti arsitektur

## Kenapa Ukurannya Mengikuti Arsitektur?

Karena tipe ini dipakai untuk hal yang berhubungan dengan **alamat memori** dan **ukuran data di memori**. Di komputer 64-bit, alamat memori panjangnya 64 bit. Di komputer 32-bit, panjangnya 32 bit. Supaya satu tipe bisa mewakili "posisi atau jumlah apa pun yang mungkin ada di memori komputer itu", ukurannya harus menyesuaikan.

## Kapan Dipakai?

**`usize` hampir selalu dipakai untuk:**

1. **Indexing** array, vector, dan slice
2. **Panjang/jumlah elemen** (`.len()` mengembalikan `usize`)

```rust
let angka = [10, 20, 30, 40];
let i: usize = 2;
println!("{}", angka[i]);   // 30
println!("{}", angka.len()); // 4 (bertipe usize)
```

Index harus `usize`. Ini tidak bisa dikompilasi:

```rust
let angka = [10, 20, 30];
let i: i32 = 1;
// println!("{}", angka[i]); // ERROR: index harus usize
println!("{}", angka[i as usize]); // OK dengan konversi
```

**`isize`** jarang dipakai. Biasanya hanya muncul saat butuh selisih/jarak antar posisi memori atau index yang bisa negatif (misalnya "mundur 2 posisi dari index sekarang").

## Aturan Praktis untuk Pemula

- Untuk angka biasa (umur, harga, skor): pakai `i32`, `u32`, `i64`, dll.
- Untuk index dan panjang koleksi: pakai `usize`.
- Jangan pakai `usize` untuk data yang harus konsisten ukurannya di semua komputer (misalnya menyimpan ke file atau mengirim lewat jaringan). Pakai `u32` atau `u64` untuk itu, karena ukurannya pasti sama di mana-mana.
- `isize`: abaikan dulu, nanti kamu akan tahu kapan perlu.
