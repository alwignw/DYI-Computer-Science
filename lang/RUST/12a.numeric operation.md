Kita mulai dari operasi numerik, topik yang kelihatannya sederhana tapi punya beberapa aturan khas Rust yang penting dipahami sejak awal.

## 1. Tipe Numerik Dasar

Rust adalah bahasa yang *statically typed* dan sangat ketat soal tipe angka.

| Kategori | Tipe |
|---|---|
| Integer bertanda (signed) | `i8`, `i16`, `i32`, `i64`, `i128`, `isize` |
| Integer tak bertanda (unsigned) | `u8`, `u16`, `u32`, `u64`, `u128`, `usize` |
| Floating point | `f32`, `f64` |

Default-nya: integer → `i32`, desimal → `f64`. `isize` dan `usize` ukurannya mengikuti arsitektur (32/64-bit), dan `usize` sering dipakai untuk indexing array.

## 2. Operator Aritmatika

```rust
fn main() {
    let a = 10;
    let b = 3;

    println!("{}", a + b); // 13
    println!("{}", a - b); // 7
    println!("{}", a * b); // 30
    println!("{}", a / b); // 3  (pembagian integer, dibulatkan ke nol!)
    println!("{}", a % b); // 1  (sisa bagi)

    let x = 10.0;
    let y = 3.0;
    println!("{}", x / y); // 3.3333333333333335
}
```

**Penting:** pembagian integer membuang bagian desimal. `-7 / 2` hasilnya `-3`, bukan `-4`.

## 3. Rust Tidak Melakukan Konversi Implisit

Ini beda dengan C atau JavaScript. Anda tidak bisa mencampur tipe:

```rust
let a: i32 = 5;
let b: i64 = 10;
// let c = a + b; // ERROR: mismatched types
let c = a as i64 + b; // OK, konversi eksplisit
```

Konversi dilakukan dengan `as`:

```rust
let f = 3.99_f64;
let i = f as i32;     // 3 (dipotong, bukan dibulatkan)
let big = 300_i32;
let small = big as u8; // 44 (wrap-around, hati-hati!)
```

Untuk konversi yang aman, gunakan `From`/`Into` atau `TryFrom`/`TryInto`:

```rust
use std::convert::TryFrom;

let a: i32 = 300;
let r = u8::try_from(a); // Err, karena 300 tidak muat di u8
let ok: i64 = i64::from(5_i32); // aman, tidak mungkin gagal
```

## 4. Integer Overflow

Ini salah satu fitur keamanan Rust yang paling penting:

- **Mode debug**: overflow menyebabkan **panic**.
- **Mode release** (`--release`): overflow **wrap-around** secara diam-diam.

Supaya perilakunya eksplisit dan konsisten, Rust menyediakan 4 keluarga method:

```rust
let x: u8 = 250;

// wrapping_*: wrap-around
println!("{}", x.wrapping_add(10)); // 4

// checked_*: kembalikan Option
println!("{:?}", x.checked_add(10)); // None
println!("{:?}", x.checked_add(5));  // Some(255)

// saturating_*: berhenti di batas min/max
println!("{}", x.saturating_add(10)); // 255

// overflowing_*: kembalikan (hasil, apakah_overflow)
println!("{:?}", x.overflowing_add(10)); // (4, true)
```

**Aturan praktis:** untuk data dari luar (input user, jaringan, file), gunakan `checked_*`. Untuk hash/kriptografi, biasanya `wrapping_*`.

## 5. Operator Assignment Gabungan

```rust
let mut n = 10;
n += 5;  // 15
n -= 3;  // 12
n *= 2;  // 24
n /= 4;  // 6
n %= 4;  // 2
```

Rust **tidak punya** `++` dan `--`. Gunakan `n += 1`.

## 6. Operasi Pada Floating Point

```rust
fn main() {
    let x: f64 = 2.0;

    println!("{}", x.powi(3));   // 8     (pangkat integer)
    println!("{}", x.powf(0.5)); // 1.414 (pangkat desimal)
    println!("{}", x.sqrt());    // 1.414...
    println!("{}", 3.7_f64.floor()); // 3
    println!("{}", 3.2_f64.ceil());  // 4
    println!("{}", 3.5_f64.round()); // 4
    println!("{}", (-5.0_f64).abs()); // 5

    // Konstanta
    println!("{}", std::f64::consts::PI);
}
```

Hati-hati dengan presisi dan nilai spesial:

```rust
println!("{}", 0.1 + 0.2 == 0.3); // false!
println!("{}", (0.1_f64 + 0.2 - 0.3).abs() < f64::EPSILON); // true

let nan = 0.0_f64 / 0.0;
println!("{}", nan.is_nan());      // true
println!("{}", nan == nan);        // false (NaN tidak sama dengan dirinya)
println!("{}", 1.0_f64 / 0.0);     // inf
```

Perhatikan: pembagian float dengan nol menghasilkan `inf`/`NaN`, tapi pembagian **integer** dengan nol akan **panic**.

## 7. Operasi Bitwise (Integer)

```rust
let a: u8 = 0b1100;
let b: u8 = 0b1010;

println!("{:04b}", a & b);  // 1000  (AND)
println!("{:04b}", a | b);  // 1110  (OR)
println!("{:04b}", a ^ b);  // 0110  (XOR)
println!("{:08b}", !a);     // 11110011 (NOT)
println!("{:b}", a << 1);   // 11000 (shift kiri)
println!("{:b}", a >> 2);   // 11    (shift kanan)
```

## 8. Literal Angka

Rust punya sintaks literal yang nyaman:

```rust
let desimal   = 1_000_000;  // underscore untuk keterbacaan
let hex       = 0xff;
let oktal     = 0o77;
let biner     = 0b1111_0000;
let byte      = b'A';       // u8 = 65
let dengan_tipe = 42u64;    // sufiks tipe
let float_tipe  = 2.5f32;
```

## 9. Method Berguna Lainnya

```rust
let n: i32 = -17;
println!("{}", n.abs());          // 17
println!("{}", n.pow(2));         // 289
println!("{}", n.rem_euclid(5));  // 3 (modulo yang selalu non-negatif)
println!("{}", n.signum());       // -1

println!("{}", 10_i32.min(20));   // 10
println!("{}", 10_i32.max(20));   // 20
println!("{}", 15_i32.clamp(0, 10)); // 10

println!("{} {}", i32::MAX, i32::MIN);
println!("{}", u8::MAX); // 255
```

Catatan: `%` di Rust mengikuti tanda pembilang (`-17 % 5 = -2`). Kalau butuh hasil non-negatif, pakai `rem_euclid`.

## Ringkasan Konsep Kunci

1. Tipe numerik **eksplisit**, tidak ada konversi otomatis.
2. Overflow: panic di debug, wrap di release, jadi pilih `checked_`/`wrapping_`/`saturating_` secara sadar.
3. `as` untuk konversi cepat (bisa kehilangan data), `TryFrom` untuk konversi aman.
4. Integer dibagi nol = panic; float dibagi nol = `inf`/`NaN`.
5. Tidak ada `++`/`--`.
