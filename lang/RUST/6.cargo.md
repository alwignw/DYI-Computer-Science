Jika Anda belajar Rust, **Cargo** adalah sahabat terbaik yang akan paling sering Anda gunakan.

**Cargo adalah *build system* sekaligus *package manager* resmi bawaan Rust.**

Jika di bahasa lain Anda harus mengunduh *tool* terpisah (seperti `npm` di Node.js, `pip` di Python, atau `Maven` di Java), Rust sudah membungkus semua kebutuhan manajemen proyek Anda ke dalam satu alat tunggal yang super sakti bernama Cargo.

---

## Apa Saja Tugas Cargo?

Cargo mengotomatiskan hampir semua tugas repetitif dalam pengembangan aplikasi. Berikut adalah fungsi-fungsi utamanya:

* **Membuat proyek baru:** Mengatur struktur folder standar hanya dengan satu perintah.
* **Mengelola *Dependencies* (Pustaka Pihak Ketiga):** Mengunduh, memperbarui, dan mengompilasi pustaka (*crates*) dari situs Crates.io secara otomatis.
* **Mengompilasi Kode:** Memanggil kompiler `rustc` di latar belakang dengan optimasi yang tepat.
* **Menjalankan Pengujian (*Testing*):** Menjalankan semua unit tes yang Anda tulis untuk memastikan tidak ada kode yang rusak.
* **Membuat Dokumentasi:** Otomatis menghasilkan halaman dokumentasi web lokal berdasarkan komentar (*comments*) yang Anda tulis di dalam kode.

## 5 Perintah Utama Cargo (Paling Sering Digunakan)

Anda menjalankan Cargo melalui terminal atau command prompt. Berikut adalah perintah-perintah wajib yang harus Anda ketahui:

### 1. `cargo new <nama_proyek>`

Perintah untuk membuat proyek Rust baru dari nol. Cargo akan otomatis membuatkan folder, file `Cargo.toml`, folder `src/`, dan inisialisasi Git (`.gitignore`).

### 2. `cargo check`

Perintah ini digunakan untuk memvalidasi kode Anda. Ia akan memeriksa apakah kode Anda ada *error* atau salah ketik tanpa benar-benar melakukan kompilasi menjadi file biner.

> **Tips:** Developer Rust sangat sering menggunakan `cargo check` saat menulis kode karena prosesnya **jauh lebih cepat** daripada melakukan kompilasi penuh.

### 3. `cargo build`

Perintah untuk mengompilasi kode menjadi file biner (*executable*).

* Secara default, ini akan menghasilkan *build* mode **Debug** (tidak terlalu dioptimasi, tetapi cepat dikompilasi, cocok saat masih develop).
* Jika ingin merilis aplikasi ke publik, gunakan `cargo build --release`. Ini akan memakan waktu kompilasi lebih lama, tetapi menghasilkan file biner yang **sangat cepat dan sangat optimal**.

### 4. `cargo run`

Perintah pintas yang sangat praktis. Perintah ini akan mengompilasi kode Anda (jika ada perubahan) dan langsung menjalankan aplikasinya saat itu juga.

### 5. `cargo test`

Rust memiliki sistem pengujian bawaan. Cukup ketik perintah ini, dan Cargo akan mencari serta menjalankan semua fungsi pengujian (*test functions*) yang Anda buat di dalam proyek.

## Menyelami `Cargo.toml` (Jantung Proyek Anda)

Seperti yang sempat kita singgung sebelumnya, `Cargo.toml` adalah file manifesto. Di sinilah Anda mengontrol proyek Anda. Formatnya menggunakan TOML yang sangat mudah dibaca manusia.

Berikut adalah contoh isi file `Cargo.toml` yang sudah ditambahkan pustaka pihak ketiga:

```toml
[package]
name = "aplikasi_saya"
version = "0.1.0"
edition = "2021" # Versi standar fitur Rust yang digunakan

# Di sini tempat mendaftarkan pustaka dari crates.io
[dependencies]
ferris-says = "0.3.1" # Pustaka untuk mencetak teks dengan maskot kepiting Rust
tokio = { version = "1.0", features = ["full"] } # Pustaka untuk pemrograman asinkron

```

Saat Anda mengetik `cargo build` setelah menambahkan baris di bawah `[dependencies]`, Cargo akan langsung menjelajah internet, mengunduh pustaka tersebut beserta semua sub-pustaka yang dibutuhkan, lalu mengompilasinya untuk Anda.

## Kesimpulan

Cargo adalah alasan besar mengapa pengalaman menulis kode di Rust (*Developer Experience*) terasa sangat modern dan menyenangkan. Anda tidak perlu pusing memikirkan cara menghubungkan file, cara *setting compiler*, atau bagaimana cara mengunduh *library*. Semuanya diselesaikan oleh Cargo.
