
# Tipe Data `char` di Rust

## Konsep Dasar

`char` adalah tipe data untuk **satu Unicode scalar value**. Literalnya ditulis dengan **tanda kutip tunggal** (`'`).

```rust
fn main() {
    let huruf: char = 'a';
    let angka: char = '7';
    let emoji: char = '😀';
    let kanji: char = '日';

    println!("{} {} {} {}", huruf, angka, emoji, kanji);
}
```

## Hal Penting yang Perlu Diingat

### 1. Ukurannya 4 byte

Berbeda dengan C/C++ yang `char`-nya 1 byte, `char` di Rust selalu **4 byte (32 bit)**.

```rust
println!("{}", std::mem::size_of::<char>()); // 4
```

Ini karena `char` bisa menampung semua karakter Unicode, bukan hanya ASCII.

### 2. Kutip tunggal vs kutip ganda

```rust
let c: char = 'a';      // char (satu karakter)
let s: &str = "a";      // string slice (teks)
```

Keduanya **tipe yang berbeda**, jadi tidak bisa saling ditukar begitu saja.

### 3. Rentang nilai valid

`char` mencakup `U+0000` sampai `U+D7FF` dan `U+E000` sampai `U+10FFFF`. Rentang `U+D800`–`U+DFFF` (surrogate) **tidak valid**.

### 4. `char` ≠ "karakter" yang dilihat manusia

`char` adalah *scalar value*, bukan *grapheme cluster*. Beberapa tampilan karakter terdiri dari beberapa `char`, misalnya emoji keluarga atau huruf dengan tanda diakritik gabungan.

```rust
let s = "👨‍👩‍👧";
println!("{}", s.chars().count()); // 5, bukan 1
```

## Operasi yang Sering Dipakai

```rust
fn main() {
    let c = 'r';

    // Pengecekan
    println!("{}", c.is_alphabetic());   // true
    println!("{}", c.is_numeric());      // false
    println!("{}", c.is_alphanumeric()); // true
    println!("{}", c.is_whitespace());   // false
    println!("{}", c.is_uppercase());    // false

    // Konversi huruf besar/kecil (mengembalikan iterator)
    println!("{}", c.to_uppercase());    // R
    let besar: char = c.to_ascii_uppercase();
    println!("{}", besar);               // R

    // Digit -> angka
    let d = '7';
    println!("{:?}", d.to_digit(10));    // Some(7)
    println!("{:?}", 'x'.to_digit(10));  // None

    // Angka -> char
    println!("{:?}", std::char::from_digit(5, 10)); // Some('5')
}
```

> `to_digit` mengembalikan `Option<u32>`, karena tidak semua `char` adalah digit. Ini pola khas Rust yang akan sering kamu temui.

## Konversi dengan Tipe Lain

```rust
fn main() {
    // char -> u32 (selalu aman)
    let n: u32 = 'A' as u32;
    println!("{}", n); // 65

    // u8 -> char (selalu aman)
    let c = 65u8 as char;
    println!("{}", c); // A

    // u32 -> char (bisa gagal, karena tidak semua u32 valid)
    let c = char::from_u32(0x41);
    println!("{:?}", c); // Some('A')

    let invalid = char::from_u32(0xD800);
    println!("{:?}", invalid); // None
}
```

Hanya `u8` yang boleh langsung di-cast `as char`. Untuk `u32`, gunakan `char::from_u32()` agar aman.

## `char` dan `String`

```rust
fn main() {
    let teks = "Halo";

    // Iterasi per char
    for c in teks.chars() {
        println!("{}", c);
    }

    // Menambah char ke String
    let mut s = String::new();
    s.push('R');
    s.push('u');
    s.push_str("st");
    println!("{}", s); // Rust

    // Mengambil char ke-n (tidak bisa pakai indeks langsung!)
    // let x = teks[0];  // ERROR
    let x = teks.chars().nth(0);
    println!("{:?}", x); // Some('H')
}
```

String di Rust disimpan sebagai **UTF-8**, sehingga satu `char` bisa memakan 1–4 byte di dalam `String`. Itulah alasan `teks[0]` tidak diizinkan.

```rust
println!("{}", 'a'.len_utf8()); // 1
println!("{}", 'é'.len_utf8()); // 2
println!("{}", '日'.len_utf8()); // 3
println!("{}", '😀'.len_utf8()); // 4
```

## Ringkasan

| Aspek | Penjelasan |
|---|---|
| Literal | `'a'` (kutip tunggal) |
| Ukuran | 4 byte |
| Isi | Satu Unicode scalar value |
| Cast aman | `u8 as char`, `char as u32` |
| Cast berisiko | `u32` → `char` lewat `char::from_u32()` (hasilnya `Option`) |
| Bukan | Bukan satu "karakter visual" secara umum |
