# Variable di Rust

Karena kamu masih pemula, kita mulai dari konsep paling dasar, dengan satu hal yang membedakan Rust dari banyak bahasa lain.

## 1. Deklarasi dengan `let`

```rust
fn main() {
    let umur = 25;
    println!("Umur: {}", umur);
}
```

Variable dibuat dengan kata kunci `let`. Rust biasanya bisa menebak tipenya sendiri (*type inference*), jadi `25` otomatis dianggap `i32`.

## 2. Secara default, variable itu *immutable*

Ini yang paling penting. Coba kode ini:

```rust
fn main() {
    let x = 5;
    x = 10; // ❌ ERROR!
}
```

Compiler akan menolak dengan pesan `cannot assign twice to immutable variable`. Di Rust, nilai yang sudah diberikan **tidak bisa diubah** kecuali kamu secara eksplisit mengizinkannya. Alasannya: kode jadi lebih aman dan mudah diprediksi, karena kamu tahu nilai itu tidak akan berubah diam-diam di tempat lain.

## 3. `mut` untuk variable yang bisa berubah

```rust
fn main() {
    let mut skor = 0;
    println!("Skor awal: {}", skor);

    skor = 10;
    println!("Skor sekarang: {}", skor);
}
```

Tambahkan `mut` (singkatan *mutable*) setelah `let`. Tapi tipenya tetap tidak boleh berubah: `skor` yang `i32` tidak bisa diisi teks.

## 4. Anotasi tipe

Kamu bisa menulis tipenya secara eksplisit dengan `:`

```rust
let harga: f64 = 19.99;
let aktif: bool = true;
let huruf: char = 'R';
let nama: &str = "Budi";
```

Ini wajib kalau compiler tidak bisa menebak, misalnya saat mengubah string menjadi angka:

```rust
let angka: u32 = "42".parse().unwrap();
```

## 5. Shadowing

Kamu boleh mendeklarasikan ulang variable dengan nama yang sama memakai `let` lagi:

```rust
fn main() {
    let x = 5;
    let x = x + 1;      // x baru = 6
    {
        let x = x * 2;  // x di dalam blok = 12
        println!("Dalam blok: {}", x);
    }
    println!("Luar blok: {}", x); // 6
}
```

Shadowing berbeda dengan `mut`, karena kamu sebenarnya membuat variable **baru**. Akibatnya **tipenya boleh berubah**:

```rust
let spasi = "   ";          // &str
let spasi = spasi.len();    // usize, valid!
```

Kalau pakai `mut`, kode di atas akan error karena tipe tidak boleh berubah.

## 6. Constant (`const`)

```rust
const MAKS_PERCOBAAN: u32 = 3;
```

Beda dengan `let`:
- Selalu immutable (tidak boleh pakai `mut`)
- Tipe **wajib** ditulis
- Nilainya harus diketahui saat kompilasi
- Konvensi nama: `HURUF_BESAR_DENGAN_UNDERSCORE`
- Bisa dideklarasikan di mana saja, termasuk di luar fungsi

## Ringkasan

| Konsep | Bisa ubah nilai? | Bisa ubah tipe? |
|---|---|---|
| `let x = 5;` | ❌ | – |
| `let mut x = 5;` | ✅ | ❌ |
| shadowing (`let x = ...` lagi) | variable baru | ✅ |
| `const X: i32 = 5;` | ❌ | – |

## Latihan kecil

Coba tebak dulu, lalu jalankan: apakah kode ini bisa dikompilasi?

```rust
fn main() {
    let mut total = 10;
    total = "sepuluh";
    println!("{}", total);
}
```

Tulis jawabanmu beserta alasannya, nanti saya koreksi. Kalau sudah paham, langkah berikutnya adalah **tipe data** (integer, float, tuple, array). Silakan tanya kalau ada bagian yang kurang jelas.
