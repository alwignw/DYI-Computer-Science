# Constant di Rust

**Constant** adalah nilai yang **tidak pernah berubah** selama program berjalan. Nilainya harus diketahui saat **compile time**, dan ditulis dengan kata kunci `const`.

## 1. Membuat constant

```rust
const MAKS_PERCOBAAN: u32 = 3;
const PI: f64 = 3.14159;

fn main() {
    println!("Maksimal percobaan: {}", MAKS_PERCOBAAN);
    println!("Nilai PI: {}", PI);
}
```

Aturan penting:

- **Tipe data wajib ditulis** (`: u32`, `: f64`), tidak bisa di-infer.
- Nama memakai **SCREAMING_SNAKE_CASE** (huruf besar dengan garis bawah).
- Tidak boleh memakai `mut`. Constant selalu immutable.

## 2. Constant vs variabel `let`

```rust
let x = 5;        // variabel, nilai bisa dihitung saat runtime
const Y: i32 = 5; // constant, harus diketahui saat compile time
```

| | `let` | `const` |
|---|---|---|
| Anotasi tipe | Opsional | **Wajib** |
| Bisa `mut` | Ya | **Tidak** |
| Nilai dari hasil runtime | Boleh | **Tidak boleh** |
| Scope | Hanya di dalam blok | Bisa di mana saja, termasuk **global** |

Contoh yang **tidak boleh**:

```rust
fn ambil_angka() -> i32 { 42 }

const A: i32 = ambil_angka(); // ERROR: bukan const fn
```

## 3. Ekspresi yang diperbolehkan

Constant boleh berisi ekspresi, selama bisa dihitung saat compile time:

```rust
const DETIK_PER_JAM: u32 = 60 * 60;
const DETIK_PER_HARI: u32 = DETIK_PER_JAM * 24;

fn main() {
    println!("{}", DETIK_PER_HARI); // 86400
}
```

Compiler menghitung `60 * 60 * 24` di awal, jadi tidak ada beban saat program berjalan.

## 4. Scope global

Constant bisa dideklarasikan di luar `main`, sehingga dapat dipakai oleh semua fungsi:

```rust
const NAMA_APLIKASI: &str = "Belajar Rust";

fn sapa() {
    println!("Selamat datang di {}", NAMA_APLIKASI);
}

fn main() {
    sapa();
    println!("{}", NAMA_APLIKASI);
}
```

Perhatikan tipe string pada constant adalah `&str`, bukan `String`.

## 5. Constant dengan array

Ini menyambung materi sebelumnya:

```rust
const HARI: [&str; 7] = [
    "Senin", "Selasa", "Rabu", "Kamis", "Jumat", "Sabtu", "Minggu",
];

fn main() {
    for h in HARI {
        println!("{}", h);
    }
}
```

## 6. Constant vs Shadowing

Variabel `let` bisa di-**shadow** (dideklarasikan ulang dengan nama sama), constant tidak bisa:

```rust
let a = 5;
let a = a * 2; // boleh, a sekarang 10

const B: i32 = 5;
const B: i32 = 10; // ERROR: B sudah didefinisikan
```

## 7. Sekilas tentang `static`

Rust punya satu lagi yang mirip, yaitu `static`:

```rust
static SALAM: &str = "Halo";
```

Perbedaan singkatnya:

- `const`: nilainya di-"tempel" (inline) ke setiap tempat pemakaiannya.
- `static`: punya **satu alamat memori tetap** selama program berjalan.

Untuk pemula, **gunakan `const` saja** dulu. `static` baru relevan di kasus lanjutan.

## Kapan memakai constant?

Gunakan untuk nilai tetap yang punya makna dan dipakai di banyak tempat, misalnya:

```rust
const PAJAK_PPN: f64 = 0.11;
const UKURAN_BUFFER: usize = 1024;
```

Keuntungannya, jika nilai perlu diubah, kamu cukup mengubah di **satu tempat**, dan kode jadi lebih mudah dibaca dibanding angka "ajaib" yang tersebar.

## Ringkasan

- Ditulis dengan `const`, **tipe wajib** disebutkan
- Nama pakai `SCREAMING_SNAKE_CASE`
- Selalu immutable, tidak bisa `mut`
- Nilai harus bisa dihitung saat **compile time**
- Bisa dideklarasikan global
- Pemula: pilih `const`, kenali `static` secara sekilas
