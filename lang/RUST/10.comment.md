Di Rust, menulis komentar bukan sekadar memberikan catatan kaki untuk diri sendiri atau rekan tim. Rust memiliki sistem komentar yang sangat cerdas. Selain digunakan untuk menjelaskan kode agar tidak dieksekusi oleh kompiler, komentar di Rust juga bisa otomatis diubah menjadi **halaman dokumentasi web resmi** untuk proyek Anda!

Mari kita bahas jenis-jenis komentar di Rust dari yang paling dasar hingga tingkat lanjut.

---

## 1. Komentar Biasa (Tidak Dieksekusi)

Komentar jenis ini murni digunakan sebagai catatan atau penjelasan kode. Kompiler Rust akan mengabaikan bagian ini sepenuhnya saat proses kompilasi.

### A. Komentar Satu Baris (`//`)

Gunakan dua garis miring untuk membuat komentar satu baris. Semua teks setelah simbol ini hingga akhir baris tidak akan dieksekusi.

```rust
fn main() {
    // Ini adalah komentar satu baris
    let x = 5; // Kita juga bisa menaruhnya di akhir baris kode
}

```

### B. Komentar Multi-baris (`/* ... */`)

Jika penjelasan Anda cukup panjang dan membutuhkan beberapa paragraf, Anda bisa membungkusnya dengan `/*` di awal dan `*/` di akhir.

```rust
fn main() {
    /* Ini adalah komentar multi-baris.
       Anda bisa menulis apa saja di sini.
       Sangat berguna untuk menonaktifkan blok kode besar saat debugging.
    */
    println!("Halo Dunia!");
}

```

## 2. Komentar Dokumentasi (*Doc Comments*)

Ini adalah fitur luar biasa di Rust. Dengan menggunakan simbol khusus, komentar yang Anda tulis akan dibaca oleh Cargo untuk digenerasikan menjadi halaman web dokumentasi resmi bergaya minimalis dan modern (seperti yang ada di Docs.rs).

### A. Dokumentasi untuk Item di Bawahnya (`///`)

Gunakan **tiga garis miring** untuk mendokumentasikan fungsi, struktur data (*struct*), atau enum yang berada tepat di bawahnya.

Menariknya, Anda bisa menulis dokumentasi ini menggunakan format **Markdown** (bisa pakai tebal, miring, list, bahkan contoh kode!).

```rust
/// Menambahkan dua angka dan mengembalikan hasilnya.
///
/// # Contoh Penggunaan
///
/// ```
/// let hasil = tambah(2, 3);
/// assert_eq!(hasil, 5);
/// ```
fn tambah(a: i32, b: i32) -> i32 {
    a + b
}

```

> **Keunggulan Rust:** Jika Anda menulis contoh kode (seperti di bagian `# Contoh Penggunaan` di atas) di dalam komentar dokumentasi, saat Anda menjalankan perintah `cargo test`, Cargo akan otomatis **menguji contoh kode di dalam komentar tersebut** untuk memastikan dokumentasi Anda tidak kedaluwarsa!

### B. Dokumentasi untuk Seluruh File/Modul (`//!`)

Gunakan garis miring ganda diikuti tanda seru untuk menulis dokumentasi yang menjelaskan **seluruh isi file atau modul**, bukan spesifik untuk satu fungsi saja. Komentar ini biasanya diletakkan di baris paling atas sebuah file.

```rust
//! # Pustaka Matematika Keren
//!
//! Pustaka ini menyediakan fungsi-fungsi dasar matematika berkinerja tinggi
//! untuk kebutuhan proyek masa depan Anda.

fn main() {
    // ...
}

```

---

## Bagaimana Cara Melihat Hasil Dokumentasi Ini?

Setelah Anda menulis komentar dokumentasi menggunakan `///` atau `//!`, Anda tinggal membuka terminal di folder proyek Anda dan menjalankan perintah sakti dari Cargo:

```bash
cargo doc --open

```

Cargo akan otomatis mengompilasi semua komentar dokumentasi Anda, mengubahnya menjadi file HTML yang interaktif dan rapi, lalu **langsung membukanya di browser web Anda**.
