Siap, kita pelan-pelan. Semua istilah ini berhubungan dengan satu hal: **bagaimana komputer menyimpan angka dalam jumlah bit yang terbatas**.

## Dasar: Angka Disimpan dalam Bit

Komputer menyimpan angka sebagai deretan bit (0 atau 1). Tipe `u8` artinya 8 bit. Dengan 8 bit, jumlah kombinasi yang mungkin hanya 2⁸ = **256 kemungkinan nilai**. Tidak bisa lebih.

Bayangkan odometer (penghitung jarak) di motor yang hanya punya 3 digit: paling kecil `000`, paling besar `999`. Ruangnya terbatas, dan itu inti dari semua istilah di bawah.

## 1. Unsigned (Tak Bertanda)

*Unsigned* artinya angka **hanya bisa nol atau positif**. Tidak ada tanda minus.

Semua 256 kombinasi dipakai untuk angka 0 sampai 255:

```rust
let a: u8 = 0;     // nilai terkecil
let b: u8 = 255;   // nilai terbesar
// let c: u8 = -1; // ERROR: unsigned tidak bisa negatif
```

Huruf **u** di `u8`, `u32`, `u64` = *unsigned*. Cocok untuk hal yang memang tidak mungkin negatif: umur, jumlah barang, indeks array, ukuran file.

## 2. Signed (Bertanda)

*Signed* artinya angka **bisa negatif, nol, atau positif**.

Karena 256 kombinasi tadi harus dibagi untuk angka negatif dan positif, rentangnya jadi bergeser:

```rust
let a: i8 = -128;  // nilai terkecil
let b: i8 = 127;   // nilai terbesar
```

Huruf **i** di `i8`, `i32`, `i64` = *integer* (signed). Totalnya tetap 256 nilai, hanya "dipindah" separuh ke sisi negatif.

Perbandingan untuk 8 bit:

| Tipe | Rentang | Jumlah nilai |
|---|---|---|
| `u8` | 0 sampai 255 | 256 |
| `i8` | -128 sampai 127 | 256 |

Rumus umum untuk n bit:
- Unsigned: 0 sampai 2ⁿ - 1
- Signed: -2ⁿ⁻¹ sampai 2ⁿ⁻¹ - 1

Cara mudah mengingat: **unsigned** = "tanpa tanda", **signed** = "pakai tanda (+/-)".

## 3. Integer Overflow

*Overflow* artinya **hasil perhitungan melebihi nilai maksimum yang bisa ditampung tipe tersebut**. Seperti gelas yang diisi air melebihi kapasitasnya, airnya tumpah.

```rust
let x: u8 = 255;  // sudah maksimum
let y = x + 1;    // hasilnya 256, tapi u8 tidak bisa menyimpan 256!
```

Itu overflow. Hasil matematikanya benar (256), tapi tidak muat di wadahnya.

Overflow juga terjadi ke arah bawah (sering disebut *underflow*):

```rust
let x: u8 = 0;
let y = x - 1;  // hasilnya -1, tapi u8 tidak bisa negatif!
```

Pada analogi odometer: motor sudah `999` km, lalu bertambah 1 km. Angkanya tidak bisa jadi `1000` karena cuma ada 3 digit.

## 4. Wrap-around (Berputar Balik)

*Wrap-around* adalah **apa yang terjadi setelah overflow**: nilainya "berputar" kembali ke ujung lain rentangnya, seperti jarum jam.

Pada odometer: `999` + 1 = `000`. Angka kembali ke awal.

Hal yang sama untuk `u8`:

```rust
255 + 1 = 0     // kembali ke awal
255 + 2 = 1
255 + 10 = 9
250 + 10 = 4    // contoh dari penjelasan tadi
```

Untuk arah sebaliknya:

```rust
0 - 1 = 255     // berputar ke ujung atas
```

Untuk signed `i8`, berputarnya dari maksimum ke minimum:

```rust
127 + 1 = -128  // dari angka terbesar, lompat ke terkecil
```

Analogi jam: pukul 12 ditambah 1 jam jadi pukul 1, bukan pukul 13. Jam "wrap-around" setiap 12 jam. Sama seperti `u8` yang wrap-around setiap 256.

## Kenapa Ini Berbahaya?

Wrap-around itu **diam-diam salah**. Program tidak error, tapi angkanya jadi tidak masuk akal:

- Saldo `0` dikurangi `1` jadi `255` (atau `4 miliar` kalau `u32`!)
- Stok barang yang negatif tiba-tiba jadi sangat banyak
- Perhitungan keuangan atau keamanan jadi salah tanpa ada peringatan

Karena itu Rust punya aturan:

| Mode | Perilaku saat overflow |
|---|---|
| **Debug** (`cargo run`) | **Panic**: program berhenti dan memberi tahu ada bug |
| **Release** (`cargo run --release`) | **Wrap-around** diam-diam |

Dan itu sebabnya ada method eksplisit:

```rust
let x: u8 = 250;

x.wrapping_add(10);    // 4        → "saya sengaja mau wrap-around"
x.checked_add(10);     // None     → "beri tahu saya kalau overflow"
x.saturating_add(10);  // 255      → "berhenti di batas maksimum"
x.overflowing_add(10); // (4,true) → "beri hasilnya DAN penanda overflow"
```

Dengan method ini Anda **memilih sendiri** perilakunya, bukan bergantung pada mode kompilasi.

## Ringkasan Singkat

| Istilah | Arti sederhana |
|---|---|
| **Unsigned** (`u8`, `u32`...) | Hanya angka ≥ 0 |
| **Signed** (`i8`, `i32`...) | Bisa negatif dan positif |
| **Overflow** | Hasil melebihi batas yang bisa ditampung tipe |
| **Wrap-around** | Nilai berputar ke ujung lain setelah overflow |
