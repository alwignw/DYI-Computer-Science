P2V atau Physical to Virtual adalah proses mengubah dan memigrasi komputer fisik atau server fisik menjadi mesin virtual (Virtual Machine atau VM).


Cara Kerja P2V
• Penyalinan Data: Perangkat lunak khusus menyalin seluruh sistem operasi, aplikasi, konfigurasi sistem, dan data dari komputer fisik.
• Pembuatan Citra (Image): Data dari mesin fisik disimpan ke dalam bentuk image atau virtual disk.
• Dijalankan di Hypervisor: Berkas tersebut dijalankan pada platform virtualisasi (hypervisor) seperti VMware ESXi, Hyper-V, atau Proxmox.



Kegunaan dan Keunggulan P2V
• Hemat Tempat & Hardware: Mengurangi kebutuhan perangkat keras fisik yang banyak dan memakan tempat.
• Efisiensi Biaya: Menurunkan biaya perawatan server dan penggunaan listrik.
• Fleksibilitas Tinggi: Memudahkan pemindahan server antar-hardware fisik dan mempermudah pemulihan bencana (disaster recovery)
