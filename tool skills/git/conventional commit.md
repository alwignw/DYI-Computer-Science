| Type       | Kapan digunakan                                | Contoh                                   |
| ---------- | ---------------------------------------------- | ---------------------------------------- |
| `feat`     | Menambah fitur baru                            | `feat(auth): add Google login`           |
| `fix`      | Memperbaiki bug                                | `fix(cart): prevent negative quantity`   |
| `refactor` | Mengubah struktur code tanpa mengubah behavior | `refactor(user): simplify validation`    |
| `test`     | Menambah/memperbaiki test                      | `test(auth): add login tests`            |
| `docs`     | Mengubah dokumentasi                           | `docs(api): update authentication guide` |
| `style`    | Formatting/style code                          | `style: format code with prettier`       |
| `chore`    | Maintenance project                            | `chore(deps): update dependencies`       |
| `build`    | Build/dependency system                        | `build: update webpack config`           |
| `ci`       | CI/CD                                          | `ci: add GitHub Actions workflow`        |
