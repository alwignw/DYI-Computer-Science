DAST (Dynamic Application Security Testing / Pengujian Keamanan Aplikasi Dinamis) adalah metode pengujian keamanan siber yang mengevaluasi aplikasi web, API, atau perangkat lunak saat sedang berjalan (runtime) dari luar ke dalam.

Metode ini sering disebut sebagai Black Box Testing atau pengujian kotak hitam karena alat atau penguji tidak memerlukan akses ke kode sumber (source code) maupun arsitektur internal aplikasi
