Umumnya, saat Anda membeli bare-metal server fisik, CPU, RAM, dan storage sudah terpasang dan langsung bisa digunakan (termasuk penuh/fully configured). Anda tidak hanya mendapatkan kerangka kosong.
Namun, di dunia server server profesional, ada dua skema pembelian yang bisa Anda pilih tergantung kebutuhan Anda:

1. Sistem Paket Utuh (Pre-configured / Fully Configured)

Ini adalah opsi yang paling umum untuk pemula atau perusahaan yang ingin praktis.
• Apa yang didapat: Server utuh yang sudah berisi motherboard, PSU, chassis, ditambah tipe CPU tertentu, kapasitas RAM tertentu (misalnya 64GB), dan storage (misalnya 2x 1TB SSD).
• Kelebihan: Tinggal colok ke listrik dan internet, instal sistem operasi, server langsung jalan.

2. Sistem Barebone (Chassis & Motherboard Only)

Osi ini biasanya dipilih oleh profesional IT atau perusahaan besar (enterprise) yang ingin merakit server dengan spesifikasi yang sangat spesifik.
• Apa yang didapat: Vendor hanya memberikan chassis (casing), motherboard, sistem pendingin (fan), dan Power Supply (PSU).
• Kelebihan: Anda bebas membeli dan memasang sendiri CPU (misal: mau pakai 2 processor sekaligus), memilih kapasitas RAM (misal: mau langsung 512GB), dan menentukan jenis storage (misal: kombinasi 4 NVMe dan 8 HDD).

Perbedaan Penting: "Membeli" vs "Menyewa"

• Jika Anda MENYEWA di Data Center (Cloud/Hosting Provider): 100% sudah pasti termasuk semua komponen (CPU, RAM, Storage). Anda tinggal pakai dan bayar bulanan.
• Jika Anda MEMBELI fisik untuk ditaruh di kantor sendiri: Anda bisa memilih opsi Paket Utuh dari merek seperti Dell, HP, atau Lenovo, atau memilih opsi Barebone dari merek seperti Supermicro untuk dirakit sendiri.
Apakah Anda berencana membeli unit fisik secara utuh untuk dipasang di kantor/data center sendiri, atau sebenarnya Anda berniat menyewa bare-metal server secara bulanan dari penyedia cloud hosting?
