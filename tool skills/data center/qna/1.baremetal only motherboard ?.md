Tidak, bare-metal server fisik bukan hanya motherboard saja.
Bare-metal server adalah satu unit komputer server fisik utuh yang lengkap dan siap beroperasi, mirip dengan komputer desktop (PC) yang Anda gunakan di rumah, namun dengan komponen kelas industri yang jauh lebih kuat dan dirancang untuk menyala 24 jam nonstop.
Disebut "bare-metal" (secara harfiah berarti "logam polos") karena server ini disewakan atau digunakan secara utuh tanpa ada lapisan virtualisasi (seperti VPS atau Cloud) di atasnya. Jadi, Anda menyewa seluruh perangkat kerasnya secara eksklusif.
Sebuah bare-metal server fisik terdiri dari komponen lengkap berikut:
• Motherboard: Papan sirkuit utama tempat semua komponen terhubung.
• Processor (CPU): Otak server, biasanya menggunakan seri khusus server seperti Intel Xeon atau AMD EPYC.
• Memori (RAM): Tempat penyimpanan data sementara dengan kapasitas besar dan fitur anti-error (ECC RAM).
• Penyimpanan (SSD/NVMe/HDD): Hard drive tempat menyimpan sistem operasi dan data.
• Power Supply Unit (PSU): Pemasok daya listrik, biasanya memiliki cadangan (redundant) agar server tidak mati jika salah satu colokan listrik bermasalah.
• Casing (Chassis): Wadah logam pelindung yang biasanya berbentuk tipis untuk dimasukkan ke dalam rak data center (rackmount).
