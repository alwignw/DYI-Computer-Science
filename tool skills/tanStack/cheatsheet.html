💡 Mengapa Dibuat?
✗Fetch manual berulang di setiap komponen
✗Tidak ada caching — data dibuang saat unmount
✗Race condition tidak tertangani
✗100 komponen sama = 100 network request
✗Data stale saat user kembali ke tab
✗Boilerplate loading/error di Vuex membengkak
✓ Otomatis: cache · dedup · sync · retry · loading state

⏱️ Cache & Timing
⏱️ staleTime TIMING
Berapa lama data dianggap FRESH
sebelum dianggap STALE
NilaiArti
0 (default)Langsung stale setelah fetch
1000 * 60 * 5Fresh selama 5 menit
InfinityTidak pernah stale
FRESH → tidak refetch meski komponen mount ulang
STALE → refetch di background pada trigger berikutnya
🗑️ gcTime TIMING
Berapa lama data tetap di cache
setelah tidak ada subscriber (unmount)
staleTime → kapan perlu di-REFETCH
gcTime → kapan data di-HAPUS dari cache

⚠️ gcTime harus ≥ staleTime
unmount → gcTime countdown
mount lagi (sebelum habis) → data masih ada ✅
gcTime habis → cache dihapus 🗑️
📊 Query Lifecycle
queryFn() selesai
↓
[FRESH] data segar, tidak refetch
↓ staleTime berlalu
[STALE] basi, refetch pada trigger
↓ komponen unmount
[INACTIVE] gcTime countdown
↓ gcTime habis
[DELETED] dihapus dari cache 🗑️
✏️ useMutation
✏️ useMutation — Anatomy WRITE 
const { mutate, mutateAsync, isPending, isError, data, reset }
  = useMutation({
    mutationFn: (payload) => api.post('/users', payload),

    onMutate: async (variables) => {
      // ← SEBELUM fetch. Ideal untuk optimistic update
      await queryClient.cancelQueries({ queryKey: ['users'] })
      const prev = queryClient.getQueryData(['users'])
      queryClient.setQueryData(['users'], old => [...old, variables])
      return { prev } // ← context untuk rollback
    },
    onSuccess: (data, variables, context) => {
      // ← kalau berhasil. Invalidate / redirect di sini
      queryClient.invalidateQueries({ queryKey: ['users'] })
    },
    onError:   (error, variables, context) => {
      // ← kalau gagal. Rollback di sini
      queryClient.setQueryData(['users'], context.prev)
    },
    onSettled: (data, error, variables, context) => {
      // ← SELALU jalan (seperti finally). Cleanup di sini
    },
  })

mutate(payload)                         // fire & forget
const result = await mutateAsync(payload) // async/await

// Callback juga bisa di level mutate() (per-call)
mutate(payload, { onSuccess: () => toast('Berhasil!') })

⚡ Optimistic Updates
⚡ Optimistic Update — Pattern Lengkap MUTATION 
const { mutate } = useMutation({
  mutationFn: (data) => api.put('/users', data),

  onMutate: async (updated) => {
    // 1. Stop refetch yg bisa overwrite
    await queryClient.cancelQueries({ queryKey: ['users'] })

    // 2. Simpan data lama untuk rollback
    const prev = queryClient.getQueryData(['users'])

    // 3. Update cache SEKARANG (UI berubah seketika)
    queryClient.setQueryData(['users'], old =>
      old.map(u => u.id === updated.id ? { ...u, ...updated } : u)
    )

    return { prev } // 4. Return context
  },

  onError: (err, vars, ctx) => {
    // ❌ Gagal → rollback
    queryClient.setQueryData(['users'], ctx.prev)
  },

  onSettled: () => {
    // 🏁 Sync final dengan server
    queryClient.invalidateQueries({ queryKey: ['users'] })
  },
})
📊 Optimistic vs Normal Flow
Normal: klik → tunggu server → UI update
Optimistic: klik → UI update LANGSUNG → server di bg

onMutate → update cache + return {prev}
onSuccess → (opsional) sync data server
onError → rollback ke {prev}
onSettled → invalidate untuk sync final
Cocok untuk: like button, toggle status,
edit inline, reorder drag-drop

🔐 Authentication AUTH 
// Axios interceptor — inject token
api.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token)
    config.headers.Authorization = `Bearer ${token}`
  return config
})

// Logout — bersihkan semua cache sensitif
const logout = () => {
  localStorage.removeItem('token')
  queryClient.clear()   // ← hapus semua
  router.push('/login')
}

// Query auth — hanya aktif kalau ada token
useQuery({
  queryKey: ['profile'],
  queryFn:  () => api.get('/me'),
  enabled:  computed(() =>
    !!localStorage.getItem('token')
  ),
  retry: (n, err) =>
    err.response?.status === 401 ? false : n < 2,
})

🗺️ Full Architecture Flow
QueryClient (singleton — otak sentral, memegang semua cache)
    │
    ├── useQuery(queryKey, queryFn) → baca · cache · sync · retry · loading state otomatis
    │       ↑ reactive: queryKey berubah → refetch otomatis
    │       ↑ staleTime: berapa lama FRESH → tidak refetch
    │       ↑ gcTime: berapa lama cache hidup setelah unmount
    │
    ├── useMutation(mutationFn) → tulis · onMutate · onSuccess · onError · onSettled
    │       ↓ onSuccess → invalidateQueries / setQueryData
    │       ↓ onMutate → optimistic update + rollback context
    │
    ├── invalidateQueries → stale + refetch aktif  |  setQueryData → update langsung tanpa fetch
    │    getQueryData → baca sinkron        |  removeQueries → hapus cache permanen
    │
    └── Patterns: Pagination · InfiniteQuery · DependentQuery · ParallelQuery · OptimisticUpdate
