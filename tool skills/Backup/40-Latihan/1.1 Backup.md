# Latihan 1.1: Backup

> [!question] Soal
> Server Historian memakai RAID 1 dan folder `D:\Backup` di server yang sama. (1) Sebutkan minimal 2 skenario data tetap hilang. (2) Apa kelemahan utama dari sisi "terpisah"?

## Jawaban saya
1. Server rusak total (motherboard/PSU): kedua disk mirror dan `D:\Backup` ikut tidak bisa diakses.
2. Ransomware: mengenkripsi database Historian dan `D:\Backup` sekaligus.
3. Kelemahan utama: backup belum terpisah secara fisik maupun infrastruktur dari server utama. Kerusakan total, ransomware, atau bencana fisik menghilangkan data utama dan backup bersamaan.

## Koreksi tutor
Benar. Tambahan:
- "Terpisah" punya dimensi fisik, logis/akses, dan lokasi.
- Skenario ketiga: salah hapus. RAID 1 langsung menyalin kesalahan ke mirror.
- `D:` kemungkinan satu disk fisik dengan data asli, jadi tidak melindungi dari kegagalan disk.
